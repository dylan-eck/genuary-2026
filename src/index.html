Genuary 2026 Art

This website hosts the art pieces I created for Genuary 2026. Genuary is an annual generative art challenge that takes place each January. Participants create generative artworks inspired by a list of 31 daily prompts. The challenge encourages experimentation with creative coding and is open to anyone interested in generative art.

I created all of the artworks using p5.js, except for day 28, which uses only raw HTML and CSS and a tiny bit of JavaScript just to get it to size properly on this website.

Click any piece below to view it. Many of the pieces utilize randomness and can be regenerated by pressing space. Source code is available at https://github.com/dylan-eck/genuary-2026
