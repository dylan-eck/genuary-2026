Dylan's Genuary 2026 Art

This website hosts the art pieces I created for Genuary 2026. Genuary is an annual generative art challenge that takes place each January. Participants create generative artworks inspired by a list of 31 daily prompts. The challenge encourages experimentation with creative coding and is open to anyone interested in generative art.

Generative art is made by writing code that defines rules or systems for creating an artwork. Each piece is an algorithm designed by the artist and executed by the computer to produce a visual result. This process is much more hands-on than simply giving a prompt to an AI image generator.
